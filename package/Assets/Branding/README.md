# Branding assets

Place captured branding assets here. See
[docs/Asset-Preparation.md](../../../docs/Asset-Preparation.md) (section 4).

- `img0.jpg` — base desktop wallpaper
- `4k/` — resolution-specific wallpapers (`img0_<WxH>.jpg`)
- `img100.jpg` — lock screen image

These are organization-specific and are not committed by default.
