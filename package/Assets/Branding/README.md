# Branding assets

Place captured branding assets here. See
[docs/Asset-Preparation.md](../../../docs/Asset-Preparation.md) (section 4).

- `img0.jpg` — base desktop wallpaper (also used for dark mode unless `img19.jpg` is supplied)
- `img19.jpg` — *optional* dark-mode wallpaper (`dark.theme`); omit to reuse `img0.jpg`
- `4k/` — resolution-specific wallpapers (`img0_<WxH>.jpg`, and `img19_<WxH>.jpg` if you supply `img19.jpg`)
- `img100.jpg` — lock screen image

These are organization-specific and are not committed by default.
